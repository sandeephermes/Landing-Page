How it works

A loop, not a suggestion

The difference between a code assistant and an agent is what happens after the first draft. Hermes runs the same five steps until the work verifies — and it costs you nothing to walk away while it does.

  1. 01

    Read

    Searches the real repository — not a snippet you pasted. Follows imports, reads the tests, learns the conventions already in the code.

  2. 02

    Write

    Edits files through real patches instead of asking you to paste a diff back in. Existing style is the style it follows.

  3. 03

    Run

    A full shell, a browser, MCP servers, your package manager. Build, migrate, deploy — whatever the task actually needs.

  4. 04

    Verify

    Runs your test suite and reads the output. A change that compiles is not a change that works, so this step is not optional.

  5. 05

    Iterate

    A failing assertion sends it back to step 2 with the actual error in hand. This is where most assistants stop.

Capabilities

It gets better the more you use it

Most tools start from zero every session. Hermes keeps what it learned — your conventions, your commands, what worked last time.

Memory

Persistent, and yours

Preferences, project constraints, environment facts. It carries them into the next session, and next month. Pluggable backends, and a place to see and edit exactly what it has stored about you.

Skills

Writes its own procedures

When it learns a non-obvious procedure for your codebase, it saves that as a skill and loads it next time. Skills are plain files you can read, edit, and share — not a black box.

Automation

Runs while you are not looking

Cron jobs, webhooks, and delegated subagents handle the overnight chores: dependency bumps, triage, batch refactors, flaky-test hunts. Results arrive where you already are, and you approve anything risky. Every command that could destroy something asks first.

Approval modes

per-session YOLO toggle · dangerous-command prompts · sandboxed · secret redaction

Models

Any provider, mid-task

OpenRouter, Anthropic, OpenAI, Google, DeepSeek, xAI, or a local model. Swap models between steps when one is better for a subtask — without restarting the work.

Control

Yours to run

One shell command installs it. No account, no telemetry, no hosted control plane. It runs on your machine, against your keys, and you can read every line of it.

Surfaces
